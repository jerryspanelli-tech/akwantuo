## Status definitions

- Not started
- In progress
- Blocked
- Under review
- Completed

## Rules

1. One accountable owner per task.
2. Task IDs are unique and never reused.
3. A task cannot be completed without acceptance evidence and review.
4. Blocked tasks must state the blocker, impact and next action.
5. Rejected work returns to active status or becomes a corrective task.
6. Phase completion and release remain CEO decisions.
7. Keep this register limited to AKWANTUO.
