# AKWANTUO

A realistic, online, open-world Ghanaian life simulation.

This is the clean rebuild branch. The complete CEO-approved development brief is tracked in GitHub Issue #4:
https://github.com/jerryspanelli-tech/akwantuo/issues/4

## Retained services
- Existing AKWANTUO Supabase project and data are preserved.
- Existing Vercel project and production configuration are preserved.

## Rebuild rules
- Build in verified stages.
- Keep secrets out of the repository.
- Do not modify production Supabase or Vercel settings without CEO approval.
- Do not claim features work without tests.
